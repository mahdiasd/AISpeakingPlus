Continuous binary frames sent over /api/v2/stt/live with endpointing and trailing silence checks.

🧠 Offline STT Engine
Sherpa-ONNX (SenseVoice Small / Zipformer) decodes speech to English text in real time with partial/final events.
Sherpa-ONNX JNI
Step 04 • Edit & Review
📝 User Review
Client displays real-time transcript. User can review, edit text if desired, and confirms message dispatch.
Interactive UI
↓ Dispatch to Ktor Backend & Orchestrator ↓
Step 05 • Prompting
🎭 Context Assembly
Backend builds prompt with Stage briefing, character persona, CEFR level (A1-C2), and previous conversation history.
StageChatService

🤖 AI Brain & Analysis
OpenAI SDK streams roleplay dialogue, evaluates grammar errors (has_error, feedback_fa), and verifies goal completion.
OpenAI / Gemini

Synthesizes character reply matching NPC gender (Male/Female voice profile) to 24kHz WAV, stored in audio_cache.
Offline Kokoro TTS

Client streams text, auto-plays audio, displays grammar hints, checks 3-star rubric, and updates progress.
