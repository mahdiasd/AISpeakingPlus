# راهنمای اجرای آزمون‌های محلی: پنل ادمین تحت وب (Quickstart)

**شاخه فیچر**: `002-web-admin-panel`  
**تاریخ**: ۱۴۰۵/۰۷/۰۶ (2026-09-27)  

این راهنما مراحل راه‌اندازی و اعتبارسنجی قابلیت‌های پنل ادمین (مدیریت Stageها با همگام‌ساز دوطرفه، مدیریت کاربران و اعطای دستی اشتراک) را گام‌به‌گام توضیح می‌دهد.

---

## ۱. پیش‌نیازها و راه‌اندازی

### ۱.۱. اجرای بک‌اند (Ktor Server)
1. اطمینان از اجرای دیتابیس PostgreSQL و Redis.
2. اجرای سرور:
   ```bash
   ./gradlew :server:run
   ```
3. بررسی سلامت سرویس:
   ```bash
   curl -s http://localhost:8080/health
   # خروجی: {"status":"UP"}
   ```

### ۱.۲. اجرای فرانت‌اند پنل وب (React + Vite)
ورود به پوشه `admin-web` و اجرای سرور توسعه Vite:
```bash
cd admin-web
npm install
npm run dev
```
آدرس پنل را در مرورگر باز کنید: `http://localhost:8081` (با پروکسی خودکار روت‌های `/api/**` به پورت 8080 سرور Ktor).

---

## ۲. سناریوهای آزمون مرحله‌به‌مرحله

### سناریوی ۱: ورود امن ادمین
1. تست امنیت مسیرهای ادمین:
   ```bash
   curl -i http://localhost:8080/api/admin/stages
   # پاسخ مورد انتظار: HTTP 401 Unauthorized
   ```
2. ورود از طریق فرم لاگین وب با اطلاعات اولیه SuperAdmin و مشاهده ورود به داشبورد اصلی.

### سناریوی ۲: ایجاد Stage جدید با همگام‌ساز دوطرفه فرم و باکس JSON
1. در پنل ادمین به بخش **Stages** رفته و روی **«ایجاد مرحله جدید»** کلیک کنید.
2. تست هماهنگی از فرم به باکس JSON:
   - صدای کاراکتر را از منوی کشویی روی `Sarah` تنظیم کنید.
   - مشاهده کنید که در باکس متنی JSON مقدار `"voiceId": "af_sarah"` بلافاصله به‌صورت زنده درج می‌شود.
3. تست هماهنگی از باکس JSON به فرم:
   - یک جیسون جدید تولیدی هوش مصنوعی را در باکس متنی پیست کنید.
   - مشاهده کنید فیلدهای فرم، عنوان، منوهای کشویی و بریفینگ بلافاصله پر می‌شوند.
4. روی دکمه «ذخیره مرحله» کلیک کنید.
5. بررسی با اندپوینت اپلیکیشن کاربران:
   ```bash
   curl -s http://localhost:8080/api/v2/stages
   ```
   مرحله جدید بلافاصله با عنوان و مشخصات وارد شده بازگردانده می‌شود.

### سناریوی ۳: جستجو و تعلیق حساب کاربر
1. در بخش **کاربران**، شماره همراه را با ارقام فارسی (مثلاً `۰۹۱۲۱۲۳۴۵۶۷`) جستجو کنید.
2. با کلیک روی «تعلیق حساب»، وضعیت را به `SUSPENDED` تغییر دهید.
3. درخواست کاربر با توکن قدیمی به سرور با خطای HTTP 403 مواجه می‌شود.
4. با زدن دکمه «فعال‌سازی»، دسترسی کاربر بلافاصله آزاد می‌شود.

### سناریوی ۴: اعطای دستی اشتراک بدون پرداخت
1. در صفحه جزئیات یک کاربر بدون اشتراک، دکمه «اعطای اشتراک» را بزنید.
2. مدت‌زمان ۳۰ روزه را انتخاب کرده و علت را بنویسید و تایید کنید.
3. در دیتابیس بررسی کنید که مقدار `grant_source = MANUAL_ADMIN` ثبت شده باشد.
4. در اپلیکیشن کاربر، قفل مراحل پولی (Stage 3 به بعد) بدون نیاز به تراکنش بانکی باز می‌شود.
